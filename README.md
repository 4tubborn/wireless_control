# Wireless Control

## Features
* Link multiple redstone consumers (e.g. powered rails and redstone lamps) to single redstone power sources, and you can use the redstone power source to control linked redstone consumers remotely!
* Use multiple linked redstone power sources to control single redstone consumers!
* Remote Control: You can create a remote control by amethyst shard, ender pearl, redstone dust, and use it to power consumers when handing it!

## Usage

### Create New Links
* Hold redstone consumers or remote controls in main hand while sneaking.
* Right click towards redstone consumers.
* Unsneak and place the redstone consumers.

### Remove Links
* Hold linked redstone consumers or remote controls in off hand while sneaking.
